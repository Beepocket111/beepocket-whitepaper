# Beepocket Whitepaper Website

Static GitHub Pages website for Beepocket Whitepaper V1.2.

## Publish with GitHub Pages
1. Upload the contents of this folder to the repository root (not the folder itself).
2. In Settings → Pages, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.

The page loads `styles.css`, `main.js`, and `beepocket-logo.jpg` using relative paths, so it works in a GitHub project repository.

Official website: https://dapp.beepocket.co/
